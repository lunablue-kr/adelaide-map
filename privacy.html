1. 수집하는 정보

이 사이트는 회원가입·로그인이 없으며, 쿠키를 사용하지 않습니다. 방문 통계는 쿠키리스 분석 도구(GoatCounter, Umami)로 페이지뷰 수준에서만 집계되며, 개인을 식별하지 않습니다. 집계에서 제외되길 원하면 주소창에 #skip-analytics를 붙여 한 번 접속하면 됩니다.

No accounts, no cookies. Visits are counted with cookieless analytics (GoatCounter, Umami) at page-view level only. Opt out anytime by visiting the site once with #skip-analytics.

2. 피드백 전송

피드백 폼은 FormSubmit(미국 소재 제3자 서비스)을 경유해 제작자 메일로 전달됩니다. 전송 내용은 미국 서버를 거치므로, 내용란에 연락처 등 개인정보를 입력하지 않는 것을 권장합니다. 닉네임은 선택 사항입니다.

Feedback is relayed via FormSubmit (a US-based service). Please avoid entering personal details in the message body.

3. 외부 리소스

페이지 로딩 과정에서 다음 외부 서버에 접속하며, 이때 브라우저가 IP 주소를 해당 서버에 전송합니다: 지도 타일(CARTO), 지도 라이브러리(cdnjs), 웹폰트(Google Fonts), 분석 2종. 이는 정적 사이트 운영에 필요한 최소 범위입니다.

Loading this site contacts external servers (map tiles, CDN, Google Fonts, analytics), which receive your IP address as part of normal HTTP requests.

4. 면책

이 지도는 참고용이며 정보의 정확성·최신성을 보증하지 않습니다. 장소는 폐업·이전될 수 있고 통계는 집계 시점의 값입니다. 거주·의료·법률 등 중요한 결정은 반드시 공식 출처를 확인하세요. 응급 상황에서는 000(호주 긴급전화)에 연락하세요.

This map is for reference only and accuracy is not guaranteed. Verify important decisions (housing, medical, legal) with official sources. In an emergency, call 000.

5. 데이터 출처·라이선스

장소·경계·통계 데이터의 출처와 라이선스는 LICENSE-DATA.md에 고지되어 있습니다. 오류·폐업 제보는 지도 팝업의 🚩 버튼 또는 피드백 폼으로 보내주세요.
